⚠️ DÉMONSTRATION DE SÉCURITÉ — EXEMPLE D'ARNAQUE Cette page n'appartient PAS à Atelier Rita. Elle a été créée pour un audit de sécurité, afin de montrer un risque. Aucune donnée n'est collectée.

Le site atelierrita.org n'empêche pas d'être affiché dans le cadre (<iframe>) d'une autre page. Ci-dessous, le vrai site est chargé à l'intérieur de cette page qui ne lui appartient pas. Un escroc peut poser par-dessus un faux formulaire, comme celui qui apparaît ici. Le formulaire ci-dessous est factice : il n'enregistre rien et renvoie vers une vidéo inoffensive, pour illustrer qu'un clic peut mener n'importe où.
